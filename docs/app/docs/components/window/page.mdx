# Window

A draggable, resizable window component that replicates macOS window behavior.

## Installation

<InstallCommand command="npx @sylonik/macos-ui add window" />

## Usage

```tsx
import { Window, WindowManager } from '@/components/window'

function App() {
  return (
    <WindowManager>
      <Window
        id="my-window"
        title="My Application"
        defaultPosition={{ x: 100, y: 100 }}
        defaultSize={{ width: 600, height: 400 }}
      >
        <div className="p-4">
          Window content goes here
        </div>
      </Window>
    </WindowManager>
  )
}
```

## Features

- **Draggable**: Click and drag the title bar to move the window
- **Resizable**: Drag window edges to resize (when enabled)
- **Traffic Lights**: macOS-style close, minimize, and maximize buttons
- **Focus Management**: Automatic z-index ordering based on focus
- **Keyboard Accessible**: Full keyboard navigation support
- **ARIA Attributes**: Proper dialog semantics for screen readers

## Accessibility

The Window component includes:

- `role="dialog"` for proper dialog semantics
- `aria-modal="true"` when focused
- `aria-labelledby` pointing to the window title
- Focus trap for modal windows
- Keyboard shortcuts for window management
