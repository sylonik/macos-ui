# Dock

A macOS-style application launcher bar with magnification effects and running indicators.

## Installation

<InstallCommand command="npx @sylonik/macos-ui add dock" />

## Usage

```tsx
import { Dock } from '@/components/dock'
import { FileText, Settings, Mail } from 'lucide-react'

function App() {
  const dockItems = [
    {
      id: 'documents',
      icon: FileText,
      label: 'Documents',
      onClick: () => console.log('Open documents'),
      isRunning: true,
    },
    {
      id: 'settings',
      icon: Settings,
      label: 'Settings',
      onClick: () => console.log('Open settings'),
      isRunning: false,
    },
    {
      id: 'mail',
      icon: Mail,
      label: 'Mail',
      onClick: () => console.log('Open mail'),
      isRunning: true,
      badge: 5,
    },
  ]

  return <Dock items={dockItems} position="bottom" magnification />
}
```

## Features

- **Magnification Effect**: Icons scale up on hover
- **Running Indicators**: Dots below running applications
- **Badges**: Notification counts or labels
- **Multiple Positions**: Bottom, left, or right placement
- **Auto-Hide**: Optional auto-hide behavior
- **Keyboard Accessible**: Full keyboard navigation
- **Smooth Animations**: Fluid transitions and effects

## Accessibility

The Dock component includes:

- `aria-label` on each dock item
- Keyboard navigation with Tab and Arrow keys
- Focus indicators
- Screen reader announcements for running state and badges

## Styling

Customize the dock appearance using CSS variables:

```css
:root {
  --dock-background: 0 0% 95%;
  --dock-blur: 40px;
  --dock-shadow: 0 5px 20px rgba(0, 0, 0, 0.15);
}
```
