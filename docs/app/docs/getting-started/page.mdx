# Getting Started

Welcome to the macOS UI component library! This guide will help you get started with installing and using the components in your React project.

## What is macOS UI?

macOS UI is a collection of beautifully designed React components that replicate the look and feel of macOS interfaces. Unlike traditional component libraries, macOS UI follows the shadcn/ui pattern: components are copied directly into your project, giving you full ownership and customization ability.

## Philosophy

- **Copy & Paste**: Components are copied into your project, not imported from node_modules
- **Full Ownership**: Modify components however you need
- **TypeScript First**: Built with TypeScript for excellent IDE support
- **Accessible**: Components follow WCAG guidelines with proper ARIA attributes
- **Customizable**: Theme system using CSS variables and Tailwind

## Prerequisites

Before you begin, make sure you have:

- Node.js 18+ installed
- A React 18+ project
- Tailwind CSS configured in your project
